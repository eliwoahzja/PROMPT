DESIGN & METHODS

Research notes.

What we used

The prompt strategy follows role, context, constraints and output formatting research, plus model/agent documentation. Styles are original briefs informed by a visual design taxonomy. No claim of a benchmarked ideal model prompt length is made.

  • AskGlitch — system prompt structures
  • Achref — 22 design directions
  • Achref — visual design keywords
  • Vercel Labs — find-skills
  • Ponytail — restraint and simplicity
  • Kilo — AGENTS.md
  • Codex — repository guidance
  • DeepSeek — model updates

How ATLAS operates

The local composer builds a transparent, deterministic prompt. Signed-in users can optionally use a server-side AI rewrite when a provider key is configured; the selected target remains the destination for the resulting prompt, not necessarily the model doing the rewriting.
