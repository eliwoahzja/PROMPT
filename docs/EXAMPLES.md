# Three before/after examples

These examples are abbreviated to show the transformation logic. The actual web page outputs the complete, selected template.

## Example 1 — Website / FreeBuff / Editorial
**Before:** “make a nice portfolio page”

**After (excerpt):**
> Build a portfolio page for an identified audience with one primary navigation/action. Inspect the existing project first and preserve its framework. Apply an editorial composition: contrasting serif title, restrained sans body copy, consistent image crops and typographic rhythm. Name practical responsive rules at 390px and handle 320px; include focus states and reduced-motion behavior. Do not use fake testimonials, filler copy, or identical feature cards. Deliver changed files, tested behavior and any blockers.

## Example 2 — Bug fixing / Codex / no style
**Before:** “fix my login issue”

**After (excerpt):**
> Inspect the existing login route, auth middleware, session configuration, and affected tests. Reproduce the failure if the environment allows; distinguish a verified root cause from assumptions. Apply a minimal fix without changing unrelated navigation or database contracts. Run focused tests and report actual file paths and outcomes. If the error cannot be reproduced, state precisely which logs are needed.

## Example 3 — Research / DeepSeek / no style
**Before:** “compare renewable energy sources”

**After (excerpt):**
> Compare solar, wind and hydropower using installation requirements, operating characteristics, intermittency, environmental effects and regional suitability. State what evidence is needed for quantitative claims and mark current pricing as unverified without up-to-date sources. Deliver a concise side-by-side table followed by a short assessment of which conditions favor each choice. Do not invent numbers or citations.

These are demonstration outputs, not empirical model runs.
